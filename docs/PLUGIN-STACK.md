# PECRAFT plugin stack

Install only builds that explicitly support the Paper/Minecraft version selected in your host panel. These are recommendations, not bundled downloads.

## Cross-play and compatibility
- Geyser — Bedrock-to-Java bridge.
- Floodgate — companion authentication plugin for Bedrock players.
- ViaVersion — supported newer Java client compatibility.
- ViaBackwards — optional older Java client compatibility, when supported.

## Essentials and permissions
- LuckPerms — ranks and permissions.
- EssentialsX — homes, warps, spawn, and moderation utilities.
- Vault — economy/permissions bridge used by many plugins.
- PlaceholderAPI — placeholders for TAB and other plugins.
- TAB — tab list, nametags, and rank display.

## Survival and protection
- WorldEdit — trusted build editing.
- WorldGuard — region protection.
- CoreProtect — action logging and rollback.
- GriefPrevention OR Lands — choose one claims system.

## Economy and gameplay
- One Vault-compatible economy provider.
- ShopGUIPlus OR EconomyShopGUI — choose one server shop.
- QuickShop-Hikari — optional player chest shops.
- One crates plugin — avoid overlapping reward systems.
- One quests plugin — optional daily/weekly tasks.
- AuraSkills — optional skills progression.

## Admin and performance
- spark — performance profiling.
- Chunky — controlled world pre-generation.
- GrimAC — optional anti-cheat; tune and test Bedrock compatibility.
- Plan — optional player analytics; configure privacy appropriately.

## Suggested ranks
Owner, Co-Owner, Admin, Moderator, Helper, Media, VIP, Default.

Use least-privilege permissions. Do not give wildcard permissions to staff by default. Install one plugin at a time, restart, and inspect the console. Test every menu from Java and Bedrock.
