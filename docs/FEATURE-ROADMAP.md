# PECRAFT feature roadmap

## Network identity
- Name: PECRAFT
- Owner account configured in setup template: XDM_GAMERX
- Theme: charcoal, violet, cyan
- Editions: Java + Bedrock via Geyser/Floodgate

## Player presentation
- TAB header/footer and rank prefixes
- Sidebar scoreboard: rank, balance, online count, ping, world
- Name tags and rank sorting
- Optional bossbar announcements

## Ranks
1. Owner
2. Co-Owner
3. Admin
4. Moderator
5. Helper
6. Media
7. VIP
8. Default

## Gameplay systems
- Survival SMP with protected spawn
- Player claims and rollback
- Economy, server shop, player shops
- Kits and timed rewards
- Crates and cosmetic rewards
- Daily/weekly missions
- Skills and progression
- Events, parkour, PvP arenas
- Multiple worlds with safe spawn routing

## Custom PECRAFT development
- PECRAFTCore: server identity, join flow, spawn and information commands
- PECRAFTMissions: custom missions and rewards
- PECRAFTProfiles: player stats and profile menu
- PECRAFTEvents: scheduled events and event utilities

All modules are planned. Features should be marked complete only after source code, build, and in-game testing exist.
