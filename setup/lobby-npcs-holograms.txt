PESMP — LOBBY NPC + HOLOGRAM SETUP
Target: Paper 1.21.1 / Java 21
This is a setup guide; it does not install anything on the live server.

RECOMMENDED LIGHTWEIGHT STACK
- Citizens: persistent NPCs with click commands.
- DecentHolograms: floating PESMP title and labels.
- EssentialsX: /warp destinations.
- Multiverse-Core: only if separate worlds are actually enabled.
Keep the initial setup small because the current host has 2 GB RAM.

INSTALL
1. Stop the server.
2. Download Citizens and DecentHolograms only from their official project pages.
3. Upload the JARs to /plugins/.
4. Start the server and confirm both appear as enabled in /plugins and the console.
5. Do not install multiple hologram plugins at once.

CREATE THE HUB
- Build the lobby in the default world first.
- Set the server spawn while standing at the exact center:
  /setspawn
- Set Essentials warps only after the destination world exists and you are standing at its safe arrival point:
  /setwarp smp
  /setwarp lifesteal
  /setwarp pvp
  /setwarp creative
  /setwarp resources

NPCS
Run these as an operator in the lobby. Create each NPC, then select it and attach its command.
Use right-click; do not use -o or temporary operator execution.
Example for SMP:
  /npc create SMP
  /npc command add -p warp smp
Repeat for each NPC:
  /npc create Lifesteal
  /npc command add -p warp lifesteal

  /npc create PvP
  /npc command add -p warp pvp

  /npc create Creative
  /npc command add -p warp creative

  /npc create Resources
  /npc command add -p warp resources

Recommended NPC appearance:
- SMP: player-type NPC with a friendly skin, name "§bSMP"
- Lifesteal: player-type NPC, name "§cLifesteal"
- PvP: player-type NPC, name "§6PvP Arena"
- Creative: player-type NPC, name "§dCreative"
- Resources: player-type NPC, name "§aResource World"

Important: the -p option makes the command run as the clicking player, so EssentialsX permissions apply normally. Do not use the -o (operator) option for public NPCs. Test with a non-operator account.

HOLOGRAM ABOVE THE MAIN GATE
Stand where the floating title should appear, then run:
  /dh create pesmp_title
  /dh line add pesmp_title <#8B5CF6>PESMP <#22D3EE>NETWORK
  /dh line add pesmp_title <gray>PLAY • EXPLORE • SURVIVE
  /dh line add pesmp_title <white>Right-click / tap an NPC to join

Move the hologram to the gateway with the installed version's move-here command (check /dh help). DecentHolograms syntax can differ between releases; confirm the exact command in /dh help before running it.

LOBBY PROTECTION
- Protect the hub region with WorldGuard if installed.
- Disable block breaking, block placing, PvP, and fire spread in the lobby.
- Keep NPCs invulnerable and prevent players from pushing them if the installed Citizens build supports it.
- Give players no Citizens or hologram administration permissions.
- Only Owner/Admin should receive setup permissions.

FINAL CHECK
- Test each NPC with a non-operator account.
- Confirm each warp exists before connecting an NPC to it.
- Test Java and Bedrock players.
- Restart once and verify NPCs and holograms persist.
- If TPS or memory drops, remove extra NPCs/animations before adding more plugins.
